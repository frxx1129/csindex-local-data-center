# 中证指数本地数据中心使用说明

## 1. 启动程序

1. 下载并解压发布 ZIP。
2. 打开解压后的 `中证指数本地数据中心` 文件夹。
3. 双击 `启动中证指数本地数据中心.cmd`。

启动脚本会自动使用当前文件夹作为数据根目录。不要只复制 EXE 文件，建议保留整个文件夹结构。

## 2. 设置抓取数量

在“抓取范围”中输入 `0–2000`：

- `0`：不发送官网请求；
- `20`、`30`：适合首次测试；
- `1000`、`2000`：抓取官网指数列表前 N 个。

更新方式首次建议选择“仅缺失”。

## 3. 断点续传

程序每完成一个接口就立即保存到本地 SQLite。抓取过程中可以点击“停止”，也可以直接关闭电脑。下次启动后输入相同数量，并选择“仅缺失”，程序会跳过已完成数据，继续抓取未完成部分。

不要选择“强制刷新”，否则会重新请求已完成的指标。

## 4. 数据和导出位置

程序会在启动目录自动创建：

- `data/csindex.db`：本地数据库；
- `data/logs`：运行日志；
- `exports`：Excel 导出文件。

点击“导出 Excel”后，会生成完整九项指标、近一年收益率排名、缺失与异常、说明四张工作表。

## 5. 网络要求

程序需要访问中证指数官网。若一直停留在“开始抓取”，先在浏览器确认官网可以打开；首次运行需要先读取官网指数列表，可能需要等待一段时间。
